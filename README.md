# React Native Vector Icons - Material Symbols Rounded

Material Symbols Rounded font for React Native Vector Icons

See the [React Native Vector Icons README](../../README.md) for more details.

## Installation

```sh
npm install @filbert-fl/material-symbols-rounded
```

## Usage

```jsx
import { MaterialSymbolsRounded } from '@filbert-fl/material-symbols-rounded';

// ...

<MaterialSymbolsRounded name="house" color="#ff0000" size={20} />
```


### Expo Config Plugin

This package ships an [Expo config plugin](../../docs/SETUP-EXPO.md). Add it to the `plugins` array in your `app.json` or `app.config.js` if you use static imports:

```json
{
  "expo": {
    "plugins": ["@filbert-fl/material-symbols-rounded"]
  }
}
```
